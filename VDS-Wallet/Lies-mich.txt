VDS-Wallet — originale Windows-Wallet in einem Extraordner
==========================================================

Das ist die offizielle Vds 0.9.9 Oberfläche (core-qt.exe, 2019)
aus: https://github.com/V-Dimension-VDS/vds-core/releases/tag/VDS

Sie liegt absichtlich in DIESEM Ordner — nicht unter
C:\Users\...\AppData und nicht im Miner-Ordner.

----------------------------------------------------------
Auf den PC legen
----------------------------------------------------------

1. Diesen ganzen Ordner nach  C:\VDS-Wallet  kopieren
   (oder das ZIP nach C:\ entpacken, sodass C:\VDS-Wallet\core-qt.exe existiert).

2. C:\VDS-Wallet\Start-VDS-Wallet.bat  doppelklicken.

3. Windows-SmartScreen: „Weitere Informationen“ → „Trotzdem ausführen“
   (die Datei ist von 2019, Windows warnt deshalb).

Daten der Wallet (wallet.dat, Blockchain) liegen dann hier:

   C:\VDS-Wallet\data\

Nicht in AppData. Du kannst den ganzen Ordner C:\VDS-Wallet sichern.

----------------------------------------------------------
Adresse für HiveOS / 666pool
----------------------------------------------------------

1. Menü Settings → Encrypt Wallet  (Passwort auf Papier notieren)
2. Menü File → Backup Wallet  → Kopie von wallet.dat auf USB
3. Reiter Receive, oder Konsole:

      Help → Debug window → Console
      getnewaddress

   Die Zeile muss mit  Vc  beginnen.

4. Genau diese Vc-Adresse ins HiveOS-Feld Wallet.

Keine 0x-Adresse, keine VID-Adresse.

----------------------------------------------------------
Wenn core-qt.exe nicht startet
----------------------------------------------------------

Dann die Browser-Wallet nutzen (docs/browser-wallet.md im Miner-Repo).
Nicht von fremden APK-/Wallet-Seiten laden.
