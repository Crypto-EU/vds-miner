# VDS-Wallet (Windows)

Die originale `core-qt.exe` von 2019 startet auf der aktuellen Chain **nicht**. Nutze die neue portable Wallet:

https://github.com/Crypto-EU/vds-miner/releases/download/v1.2.0/VDS-Wallet.zip

Nach **`C:\VDS-Wallet`** entpacken, **`Start-VDS-Wallet.bat`** starten.

Im Repo: Ordner [VDS-Wallet/](../VDS-Wallet/). Bauen: `./scripts/build-wallet.sh`.

`Wallet.zip` in diesem Ordner ist nur noch das Archiv der alten Vds-0.9.9-Oberfläche (SHA256 `8f59cc41f9c1d4948fbbc305e45c789dc926f2bec9e87c689c56abdab57983c5`). Nicht verwenden.

Keine `0x…`-ETH-Adresse verwenden.
